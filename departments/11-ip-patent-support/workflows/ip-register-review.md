# Workflow: IP Register Review (quarterly)

1. Pull the register and the deadline calendar. Date the review.
2. For each row, confirm the source document is on file and the status text matches it. Mark mismatches.
3. Confirm `owner_entity` matches the assignment record (`../skills/assignment-gap-check/SKILL.md`).
4. List new products, features, names and disclosures since last review that have no register row. Send to `patent-support-analyst` or `trademark-support-analyst`.
5. Scan deadlines in the next 120 days; send to the coordinator.
6. Review the trade secret register and the offboarding log.
7. **Gate (sign-off):** coordinator and principal approve the review note; counsel receives the gap and deadline lists.
8. Save the dated review note in the IP file.
