# Workflow: Pre-Disclosure Check

Run before any external sharing: investor deck, pilot, demo, talk, paper, website post, open-source release.

1. What exactly will be shown? List the content.
2. Does it reveal an invention not yet reviewed by counsel? If yes, stop and use `invention-to-counsel.md`.
3. Is an NDA needed and in place? (`../templates/nda-marking-checklist.md`)
4. Mark documents; reduce detail to the minimum.
5. **Gate (sign-off):** coordinator and principal approve; counsel is consulted for new inventions.
6. Log the disclosure.
