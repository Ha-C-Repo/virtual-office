# Trade Secret Program

## When to use
Setting up IP hygiene, onboarding or offboarding someone with access, before sharing technical detail, and when deciding whether to keep something secret instead of filing.

## Inputs
List of candidate secrets (formulas, source code, supplier terms, process know-how, customer lists, test data), access list, `../../templates/trade-secret-register.md`.

## Steps
1. Name each secret by description only. Never write the secret itself in the register.
2. Record where it lives, who may access it, and the protection measures in force (access control, NDA, marking, need-to-know, logging).
3. Check each person with access has a signed confidentiality agreement and assignment (`../assignment-gap-check/SKILL.md`).
4. On offboarding: remove access, collect devices, remind of continuing obligations, log it.
5. Before any disclosure run `../../workflows/pre-disclosure-check.md`.
6. Raise to counsel the choice between filing and keeping secret; the coordinator does not decide.

## Outputs
Trade secret register, offboarding record, gap list.

## Gates
The register never contains the secret. Counsel reviews the protection measures annually.
