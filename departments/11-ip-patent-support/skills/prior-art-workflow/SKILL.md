# Prior-Art Workflow

## Steps
1. Define the features to search (3-6 key technical features) and synonyms.
2. Search public patent databases, scholarly sources and product literature. Record query, source, date.
3. For each relevant item, log: identifier as shown in the source, title, date, what it discloses, which feature it touches, how it differs (`../../templates/prior-art-log.md`).
4. Mark each hit: close, partial, background.
5. Summarize gaps: features with no close art, features with strong art.
6. Send to counsel.

## Rules
Verify, do not generate. Only log items you actually opened. Never state that an invention is or is not patentable.
