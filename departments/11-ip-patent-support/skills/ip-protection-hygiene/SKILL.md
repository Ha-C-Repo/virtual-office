# IP Protection Hygiene

## Checklist
1. **Privilege.** Keep counsel communications in a restricted folder; do not paste them into shared channels or forward to third parties.
2. **NDAs.** Signed before sharing non-public technical detail; documents marked confidential (`../../templates/nda-marking-checklist.md`).
3. **Assignments.** Every employee, founder and contractor who contributes signs an invention assignment before contributing. Keep the signed copies in the entity file.
4. **Conception evidence.** Dated design records, repository history, lab notebooks. Record who conceived what, when.
5. **Waiver risk.** Public posts, demos, conference talks, pilots and investor decks can disclose inventions. Run `../../workflows/pre-disclosure-check.md` first.
6. **Third-party code and data.** Track licenses of included components.
7. **Marking.** Use confidentiality legends consistently.

Report gaps to the coordinator; counsel fixes them.
