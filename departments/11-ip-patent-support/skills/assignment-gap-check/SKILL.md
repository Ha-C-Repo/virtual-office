# Assignment Gap Check

## When to use
Before filing preparation, before a pilot or investor diligence, on each new contributor, and quarterly.

## Inputs
Contributor list (founders, employees, contractors, advisors, students, vendors who wrote code or designs), signed agreements on file, repository and design-record authorship, `../../templates/assignment-gap-check.md`.

## Steps
1. List everyone who contributed to code, hardware, designs or documents, from repository history and design records.
2. For each, record: agreement type, signed date, file location, scope (does it cover work done before the signing date?).
3. Mark gaps: no agreement, unsigned, signed after work began, scope does not cover prior work, third-party employer may claim the work.
4. Send the gap list to the coordinator for counsel. Do not draft the assignment language here.

## Outputs
Gap table with owner and next step for each row.

## Gates
Counsel closes gaps. The check is re-run after counsel confirms.
