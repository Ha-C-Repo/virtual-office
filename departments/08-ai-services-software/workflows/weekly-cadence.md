# Workflow: Weekly and Quarterly Cadence

## Weekly
1. Customer health scoring pass (`../skills/customer-health-scoring/SKILL.md`).
2. AI cost review (`../skills/ai-cost-telemetry/SKILL.md`).
3. Support quality audit: sample tickets; check AI-first triage and escalation correctness.
4. Open-items review: spec index statuses, security ledger, handoff leftovers.
5. Brief to the principal in plain prose.

## Monthly
- Context and template audit: retire unused instructions; promote recurring tasks to templates.
- Churn reason code review.

## Quarterly
- Recalibrate health model against actual renewals.
- External penetration test cadence check.
- SOC 2 style evidence collection review.
- Pricing experiment review.
