# Compliance Triage

## When to use
A prospect or customer sends a security, privacy or compliance questionnaire.

## Decision tree
1. Is real revenue tied to it? If no, answer briefly or decline politely.
2. Can it be answered from existing materials (policies, architecture notes, evidence folder)? If yes, answer from them and cite the source.
3. Is a framework unmet (for example, a certification not held)? Disclose it honestly, state what is in place and any roadmap that is approved. Never imply compliance that does not exist.
4. Does it need an attorney (indemnity, liability, data processing terms)? Route to counsel.
5. Is it something we refuse (unreasonable audit rights, unlimited liability)? Decline and explain.

## Outputs
Answered questionnaire with a source reference for each answer, a list of gaps, and a note for the principal.

## Gates
Principal approves before it is sent. Never state a certification, test result or policy that you cannot point to.
