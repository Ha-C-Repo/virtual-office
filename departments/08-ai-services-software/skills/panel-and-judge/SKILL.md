# Panel and Judge

## When to use
Open research or design questions where perspectives differ: market scans, architecture options, threat modeling.

## Do not use for
Facts that have one source of truth (a customer's contract term, a table's actual schema, a price in a quote). Look those up.

## Steps
1. Write one neutral question with the same context for every panelist.
2. Collect answers independently; do not let panelists see each other's output.
3. Judge: list points of consensus, points of conflict, and gaps nobody covered.
4. Check each factual claim against a primary source before using it.
5. Present a recommendation with the dissent noted.

## Outputs
A short synthesis: consensus, conflicts, gaps, recommendation, claims still unverified.
