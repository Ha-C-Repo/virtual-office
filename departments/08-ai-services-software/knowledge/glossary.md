# Glossary: AI Services and Software

- **Tenant / organization:** the unit of data isolation. Every query is scoped by tenant id.
- **Vertical config:** per-industry defaults for AI behavior (job types, scope, exclusions, line items, compliance framework, pricing model, demo defaults).
- **Takeoff:** AI extraction of scope and quantities from documents into priced line items; usually an asynchronous job (enqueue, then poll).
- **Relationship intelligence layer:** tenant-scoped ingestion of email, calendar and chat into contact profiles, company dossiers and deal timelines with provenance metadata.
- **Geofence auto clock:** location-triggered time entries; GPS ping; alerts.
- **IDOR:** insecure direct object reference; access by id without ownership check.
- **Staged inert:** code deployed but disabled until activation.
- **Constitution:** the highest-priority rules file; never overridden by a prompt.
- **Spec stages:** constitution check, specify, clarify, plan, tasks, implement.
- **Slop / kill list:** banned writing patterns.
- **NRR / GRR:** net / gross revenue retention. **MRR / ARR:** monthly / annual recurring revenue. **CAC payback, ARPU, QBR, CSAT, NPS:** standard SaaS measures.
- **Flat-rate pricing:** one price per tier with all features unlocked, used as a brand promise.
- **Drift:** divergence between served code, repository and other copies.
- **Cowork mode vs advisory mode:** assistant with file access vs chat-only advice.
- **Machine-facing vs human-facing documents:** structured, front-loaded files for agents vs plain prose for people.
- **Ubiquitous-language ledger:** table tying business terms to code symbols.
- **Panel-and-judge:** multi-assistant synthesis method.
