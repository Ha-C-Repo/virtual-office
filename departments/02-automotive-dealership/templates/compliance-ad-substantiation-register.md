## Rules
1. Check the register before approving any ad, caption, script or listing that makes a claim.
2. Conditional claims ("clean history report", "one owner", "no accidents") need the substantiating document on the unit record. Warn if present, block if absent.
3. Status UNSUBSTANTIATED means the claim is blocked everywhere it appears.
4. Empty is a valid state at go-live only if declared explicitly: "register seeded: none, no claims in use".
