# 05 Award to Project Controls

Owner: contract-administrator. Sign-off: {{APPROVER_ROLE}}.

1. Contract signed. Create the nine-folder skeleton (`../templates/project-folder-skeleton.md`). Folders are never deleted, even when empty.
2. Build the per-project loader and context layer (`../templates/project-loader.md`).
3. Build the obligations register from the contract (`../templates/obligations-register.md`) and start the correspondence register. Run contract-risk-review on the executed contract.
4. Convert award to budget (`../skills/award-to-budget/SKILL.md`). Cost codes mirror bid lines, explicit management reserve. GATE: baseline frozen only after approval.
5. Order long-lead material (`09-steel-procurement.md`).
6. Each pay-app cycle: update obligations status, percent complete and the schedule of values (`08-milestone-billing-and-receivables.md`).
7. Scope-creep watch on all client communications, leading to `06-scope-creep-to-change-order.md` and, for client-caused delay, `07-contract-notice.md`.
8. Closeout: final pay application, release of retainage request, warranty and as-built documentation, lessons learned feeding the rate-band library.

Live registers are read and written directly, never mirrored.
