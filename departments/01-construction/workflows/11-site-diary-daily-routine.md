# 11 Site Diary Daily Routine

Owner: field-reporting-clerk. Approval: site supervisor (never automatic).

1. Pull unprocessed raw messages (portal, chat exports, voice-note transcripts).
2. Extract to DIARY, LABOR, QUANTITIES, DELIVERIES, DELAYS, TASKS with confidence tags. LOW rows generate clarifying questions.
3. Mark rows processed only after all targets are written.
4. Supervisor approves in the portal.
5. Weather: compare with the contract threshold; flag candidate extension-of-time events to contract-administrator.
6. Friday: one-page digest (`../templates/weekly-owner-digest.md`): days worked, crew hours, progress against budget, delays verbatim, open tasks. Supplier names remain on the internal tab.
7. Feed percent complete to billing only from approved rows.
8. Run in sandbox before going live on a new job.
