# Harnesses: 01-construction

Stdlib Python 3 tools with self-tests. Numbers from these tools win over model arithmetic. Selftest figures are illustrative; real inputs come from the owner or from dated documents.

| File | Purpose |
|---|---|
| `bid_buildup.py` | Steel tonnage and sequential-markup bid price. Weights per foot come from the estimator's own section tables. |

Run `python bid_buildup.py --selftest` after any change. Run `python bid_buildup.py --help` for usage.
