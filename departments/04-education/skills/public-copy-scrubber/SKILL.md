# Public Copy Scrubber

## When to use
Before any store listing, release note, website text or social post leaves the studio.

## Inputs
Draft public copy.

## Steps
1. Run the machine validator. A non-zero exit blocks.
2. Judgment pass. FAIL on:
   - internal economics or vendor-cost detail
   - integrity-boundary mechanics (how refusals work, what is filtered)
   - fabricated social proof (reviews, user counts, quotes)
   - em-dashes and filler words
   - outcome or grade promises
3. Rewrite with short, concrete sentences.
4. Re-run the validator.

## Outputs
Scrub report and cleaned copy.

## Gates
The owner approves public text. A scrubbed draft is still a draft.
