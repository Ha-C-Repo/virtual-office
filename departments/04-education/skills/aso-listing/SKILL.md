# ASO Listing

## When to use
Choosing the title, short description and keyword fields.

## Inputs
Candidate keywords, verified volume data with source and date (if a keyword tool is connected), competitor teardowns.

## Steps
1. Build candidates from what the product actually does.
2. Remove anything on the kill-list: cheating intent, undetectable output, ghostwriting, "write my paper", "do my homework for me".
3. Attach a verified volume and date to each kept keyword. No volume data means mark UNMEASURED and do not rank by guess.
4. Place keywords naturally; no stuffing; no competitor brand names.
5. Run the scrub.

## Outputs
Keyword table: keyword, volume, source, date, placement.

## Gates
Kill-list applies to keywords as well as copy. Owner approves.
