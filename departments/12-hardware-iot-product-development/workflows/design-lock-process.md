# Workflow: Design Lock Process

1. A decision is needed. Owner drafts `../templates/design-lock.md` as proposed.
2. Affected areas comment within {{REVIEW_DAYS}} days.
3. Security, privacy and regulatory check (`../skills/connected-product-risk-review/SKILL.md`).
4. **Gate:** product development lead approves; **Gate:** principal approves if spend or customer-facing impact.
5. Mark locked; file in the architecture folder; notify areas.
6. Send a copy to the IP coordinator (department 11) to date conception.
7. Changes create a new lock that supersedes the old one.
