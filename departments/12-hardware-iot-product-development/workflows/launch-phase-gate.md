# Workflow: Launch Phase Gate

1. Fill `../templates/launch-phase-checklist.md` with the product lead.
2. Collect evidence for each criterion.
3. Request reviews: IP (FTO pre-review through department 11), privacy, safety, security, regulatory, legal for agreements.
4. Resolve or accept gaps explicitly.
5. **Gate (sign-off):** principal approves phase transition.
6. Announce internally; update roadmap; communicate externally only with approval.
