# Workflow: Supplier Qualification

1. State needs and criteria (`../skills/supplier-qualification/SKILL.md`).
2. NDA and IP terms in place before sharing designs.
3. Collect the same information from each candidate; log gaps.
4. Order samples (principal approves); test and record.
5. Complete the scorecard with evidence.
6. Identify single-source risk and backup.
7. **Gate (sign-off):** principal approves; counsel reviews supply agreement.
8. File the scorecard; set the annual review date.
