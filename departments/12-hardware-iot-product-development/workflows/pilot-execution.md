# Workflow: Pilot Execution

1. Complete `../templates/pilot-plan.md`; principal and counsel approve (pilot agreement).
2. Run the pre-disclosure check and confirm NDAs.
3. Provision devices with unique identities; record serial roles, not personal data.
4. Onboard participants; confirm consent before any data flows.
5. Weekly review: metrics vs thresholds, support tickets, failures, safety events.
6. Stop criterion met: pause and notify the principal the same day.
7. Exit: recover devices, delete data per plan, write the final report with evidence.
8. **Gate (sign-off):** principal decides on the next phase using `launch-phase-gate.md`.
