# Launch Phase Gating

## Phases
1. **Pre-launch:** prototype, architecture locks, IP review, regulatory path identified.
2. **Pilot:** limited units and users, written pilot agreement, consent and privacy notices, support plan, feedback loop.
3. **Commercial:** repeatable manufacturing, certification complete, support and warranty processes, pricing.
4. **Scale:** supply capacity, channel partners, fleet operations and OTA discipline.

## Steps
1. Define exit criteria for the current phase with the product lead (measurable, dated).
2. Review evidence; list gaps.
3. Run IP check (FTO pre-review before pilot), privacy review, safety review.
4. Principal approves the transition.
5. Record in `../../templates/launch-phase-checklist.md`.

Exit criteria numbers are set by the team ({{CRITERIA}}); do not copy numbers from other companies.
