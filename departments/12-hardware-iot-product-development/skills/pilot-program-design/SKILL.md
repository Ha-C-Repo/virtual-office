# Pilot Program Design

## When to use
Before the pilot phase gate in `launch-phase-gating`.

## Inputs
Build revision and design locks, `../../templates/pilot-plan.md`, pilot agreement draft (counsel), privacy notice, support plan.

## Steps
1. State the questions the pilot must answer (technical, usability, operations, unit economics).
2. Set size, duration, sites and participant criteria. Keep the first pilot small enough to support by hand.
3. Define success and stop criteria in measurable terms, written before the pilot starts.
4. Define data collected, consent, retention, access and deletion (`connected-product-risk-review`).
5. Define support: contact path, response targets, replacement and return process, safety escalation.
6. Define the exit: device recovery, data deletion, final report.
7. Run the pre-disclosure check and confirm NDAs and counsel-reviewed pilot terms.

## Outputs
Pilot plan, participant agreement checklist, evidence log template.

## Gates
Principal approval and counsel review of the pilot agreement. Safety-relevant failures stop the pilot.
