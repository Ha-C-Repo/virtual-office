# Workflow: Decide Session

1. Owner has read the memo; pre-wire stakeholders.
2. Run the session (`../skills/decision-session/SKILL.md`), using `../skills/strategic-choice-cascade/SKILL.md` and `../skills/pre-mortem-and-inversion/SKILL.md`.
3. Capture two or three commitments, owners, 90-day metrics, stop-doing list.
4. Draft `../templates/decision-memo.md` and `../templates/thirty-day-plan.md` within {{MEMO_HOURS}} hours.
5. Editor pass.
6. **Gate (sign-off):** principal approves before sending.
7. Offer the optional implementation retainer only if the client signals need.
