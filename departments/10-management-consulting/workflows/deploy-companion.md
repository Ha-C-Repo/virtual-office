# Workflow: Deploy Companion (months 4-12)

1. Monthly cadence: review metrics against the 90-day targets.
2. Remove blockers; escalate decisions that are stuck to the owner.
3. Update the one-page plan each quarter (`../templates/one-page-plan.md`).
4. Run a quarterly pre-mortem on the next initiative.
5. Written monthly note to the owner: what moved, what did not, next decision needed.
6. **Gate:** retainer scope changes need principal approval.
