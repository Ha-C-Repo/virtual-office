# Workflow: Design Phase (weeks 7-10)

1. Confirm scope of design work; separate agreement if beyond the base engagement.
2. Operating model: capability map, decision rights, org spans, cadence (`../skills/operating-model-design/SKILL.md`).
3. Pricing, if relevant (`../skills/value-based-pricing/SKILL.md`).
4. Driver-based model with three scenarios (`../skills/driver-based-financial-model/SKILL.md`).
5. Pilot plan for 30-60 days.
6. Editor pass; **Gate:** principal approves; client reviews.
