## Structure check (`../skills/deliverable-structure/SKILL.md`)
Answer first; situation, complication, question framing; action titles that state the conclusion; sections mutually exclusive and collectively exhaustive.

## Voice (`../skills/voice-audit/SKILL.md`)
Three modes: internal, client-facing, logistics and follow-up. First line is the band label. Run the five passes: dash sweep, banned vocabulary, vague hedge, specificity, length and structure. Log the audit using `../templates/voice-audit-log.md`.

## Rules
- Plain English. Specific over vague. Earn every hedge.
- Do not change meaning to fix style; query the author instead.
- Block release if a claim has no source or an assumption is unlabeled.
