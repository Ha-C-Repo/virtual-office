# Diagnose First

## When to use
Start of every engagement; any time a client asks for a solution before the problem is clear.

## Steps
1. Reframe the stated problem in one sentence; test it with "what would have to be true for this to be the real problem?"
2. Collect data (financials, pipeline, customer list, org chart, pricing, capacity).
3. Interview people (owner first, then others).
4. Draft conclusions only after steps 2-3; write what would change your mind.
5. Answer the three diagnostic questions; write the memo (`../../templates/diagnostic-memo.md`).

## Traps to avoid
Boiling the ocean; framework over fit; solution before diagnosis; telling the owner what they want to hear.
