# Website Build

1. **Brief.** Page job, audience, business, references. Gate: requester approves.
2. **Brand tokens** current and approved (`../templates/brand-tokens.md`).
3. **Master website prompt** completed (`../templates/master-website-prompt.md`).
4. **Required disclosures** collected verbatim from the originating department. Gate: any placeholder remaining in a required disclosure blocks the build.
5. **Hero and visuals** per `../skills/anti-ai-look-laws/SKILL.md`; cost gate if paid generation.
6. **Build** sections in order (`../skills/web-design-pipeline/SKILL.md`).
7. **Design loop and critic pass** (`../skills/design-loop-critic/SKILL.md`).
8. **Measure:** accessibility, responsive layouts, performance, links, forms.
9. **Review** by the requester and, for regulated content, the compliance owner. Gate: blocking.
10. **Publish** after logged approval; record version and date; set review date.

Rule: no fabricated testimonials, ratings, licenses, awards or statistics.
