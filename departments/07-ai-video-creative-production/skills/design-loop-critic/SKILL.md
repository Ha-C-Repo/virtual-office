# Design Loop and Critic Pass

## When to use
Web pages, thumbnails, title cards, storyboard frames, brand boards.

## Steps
1. Define the scoring rubric first: hierarchy, typography, color contrast, spacing, brand fit, distinctiveness, accessibility, message clarity. Score each 1 to 5 with a one-line reason.
2. Produce version 1. Score it honestly against the rubric.
3. Revise the lowest-scoring items. Re-score. Stop when the target is met or the iteration cap from the cost gate is reached.
4. **Critic pass:** a separate review (second persona or different pass with fresh context) lists the five biggest problems and any template-default look. Address them.
5. Present to a human with the final rubric and what changed.

## Outputs
Final artifact, rubric scores per iteration, critic notes.

## Gates
Rubric and cap are set before iteration. The human decides acceptance.
