# Brand Style Systems

## When to use
At the start of each production and each new client.

## Components
1. **Style token:** a short descriptor reused in every prompt (grade, grain, lens, palette).
2. **Anti-AI laws** applied (`../anti-ai-look-laws/SKILL.md`).
3. **Voice rules:** narration tone, vocabulary, banned phrases.
4. **Brand tokens:** name, version, status, identity (company, positioning line, signature line), logo (rule, lockups, pairing), surfaces (colors per surface), donts (banned strings, warn strings, rules). Use `../../templates/brand-tokens.md`.
5. Two common looks: **corporate cinematic** (restrained, steady, deep tones, authority) and **luxury premium** (slow, high-contrast, shallow depth, minimal). Pick or define one per production; do not mix.

## Steps
1. Gather the client's existing brand assets; do not invent a logo.
2. Fill the tokens file; mark sources.
3. Generate a style test frame; get approval.
4. Lock. Changes need a new version number.

## Gates
Logo rules are followed exactly. Retired lines and banned strings never appear in output.
