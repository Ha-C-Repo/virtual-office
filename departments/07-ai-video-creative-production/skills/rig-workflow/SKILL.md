# Rig Workflow

## When to use
Children's series where characters must stay identical across episodes and generative footage is used only for what rigs cannot do.

## Steps
1. **Turnaround:** approved character sheet (front, three-quarter, profile, back) from the series bible.
2. **Layers:** separate head, torso, arms, legs, eyes, brows, hair, accessories as clean layers.
3. **Rig once:** build the skeleton and pivots once; reuse in every episode.
4. **Mouth-shape set:** a fixed set of mouth shapes mapped to speech sounds; lip-sync from the voiceover track.
5. **Animate** on generated background plates (wide staging, static or slow camera).
6. **Generative footage** only for effects the rig cannot do (weather, crowds at distance, magic), shot wide and reviewed frame by frame.
7. Export and send to frame review.

## Gates
- Character design changes go through the series bible first.
- Rig file is backed up and versioned; never overwrite.
