# Prequalification Response

Agent: prequalification specialist. Skills: `../skills/prequalification-response/SKILL.md`, `../skills/insurance-gap-analysis/SKILL.md`.

## Steps
1. Receive the questionnaire; parse questions into a list.
2. Check that the written program files exist (`../templates/safety-program-checklist.md`).
3. For each question: identify program, locate source, extract text, draft answer (`../templates/prequalification-answer.md`), tag confidence.
4. Flag gaps; do not invent policy.
5. Run the insurance and controls gap analysis (`../templates/insurance-gap-analysis.md`).
6. Update the status tracker (`../templates/prequalification-status.md`).
7. Produce the "today's actions" list.
8. GATE: {{OWNER_ROLE}} reviews all LOW confidence answers and all gaps, then approves submission.
