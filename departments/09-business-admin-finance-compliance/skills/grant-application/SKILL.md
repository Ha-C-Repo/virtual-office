# Grant application

## When to use
When a grant opportunity is identified.

## Steps
1. Extract the funder's criteria, deadline, required attachments and scoring rubric into a checklist.
2. Map each criterion to evidence in the registers and reports.
3. Draft each section per `../../templates/grant-application-outline.md`. Keep to word limits.
4. Budget: tie each line to a source quote or schedule; label estimates.
5. List missing attachments and who must supply them.
6. Final check against the rubric, then the scrubber.

## Outputs
Draft application, evidence map, attachment checklist.

## Gates
Never state outcomes or metrics that are not in the registers. {{OWNER_ROLE}} approves and submits.
