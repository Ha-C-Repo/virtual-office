# Prequalification response

## When to use
A client or platform sends a safety, insurance, cyber or procedures questionnaire.

## Steps
1. Read the questionnaire item.
2. Identify which written program it references.
3. Locate the source policy document. Use `../../templates/safety-program-checklist.md` for the program list.
4. Extract the policy text.
5. Format the answer: direct statement; program and section reference; procedures; responsible role; training frequency; confidence HIGH, MEDIUM or LOW.
6. If the program or section is absent, write FLAG: gap. Never invent policy. Where a standalone program is absent, use the master safety manual as a fallback and say so.
7. Update the platform status tracker and the outstanding-items list (`../../templates/prequalification-status.md`).
8. Assemble the answer set (`../../templates/prequalification-answer.md`).

## Outputs
Draft answers, gap list, status tracker.

## Gates
{{OWNER_ROLE}} approves before submission. Company identifiers and policy numbers stay as placeholders in drafts.
