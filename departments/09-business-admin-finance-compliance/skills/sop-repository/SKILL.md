# SOP repository

## When to use
When an SOP is added or revised, and when any workflow cites a protocol.

## Steps
1. Index each SOP: document number, title, effective date, file present (yes or no).
2. When two documents conflict on protocol, the source SOP wins. Flag the conflict to {{OWNER_ROLE}}; do not silently choose.
3. Revisions are additive with effective dates; prior versions stay.
4. Missing files are listed as gaps.

## Outputs
Index (`../../templates/sop-index.md`) and conflict list.

## Gates
Never paraphrase an SOP as if it were the SOP; quote and cite number and effective date.
