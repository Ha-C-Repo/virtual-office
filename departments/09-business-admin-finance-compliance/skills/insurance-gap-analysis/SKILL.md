# Insurance and controls gap analysis

## When to use
When a prequalification request or a contract states required coverage or control levels.

## Steps
1. List required items: liability limits, workers compensation, auto, umbrella, professional if applicable, cyber score, multi-factor authentication, welding or work procedure qualifications.
2. List current values from the certificate or register (placeholders in shared drafts).
3. Compute the gap for each (required minus current). Mark MET, SHORT or UNVERIFIED.
4. Recommend next step categories: ask broker for quote, ask client for waiver, implement control, obtain qualification.

## Outputs
Gap table (`../../templates/insurance-gap-analysis.md`).

## Gates
Do not state coverage that is not on a certificate. {{OWNER_ROLE}} decides on purchase or waiver request.
