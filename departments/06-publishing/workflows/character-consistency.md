# Character Consistency (7 steps)

Use for any illustrated or animated series. Video uses the same flow (see `../../07-ai-video-creative-production/workflows/character-consistency-video.md`).

1. **Text bible.** Complete `../templates/character-bible.md`. Run the IP screen first. Gate: lookalike found means stop and redesign.
2. **Model sheet and grids.** Front, three-quarter, profile, three-quarter back, back, expression grid, on a plain background. Gate: art-director and a human approve.
3. **Style lock.** One style family, 5 to 7 colors, recorded.
4. **Location bible.** `../templates/location-bible.md` for every recurring place.
5. **Scene generation.** Attach canonical anchors on every call. Multi-character scenes: identities, then positions, then actions.
6. **Repair, not regenerate.** Inpaint drift (outfit, face, hands). Re-roll only when the composition itself is wrong.
7. **Flip-through QC.** Review all spreads in sequence. Gate: human sign-off logged. **BLOCKING.**

## Iron rules
- Never chain output N into output N+1.
- The bible is the only source of truth; fix the bible first if the design must change, then re-anchor.
- Log image AI role in the production log.
