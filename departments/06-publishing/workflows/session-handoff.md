# Session Handoff

Defeats session amnesia on long initiatives.

1. At the end of a work session, write a dated HANDOFF document with a version number: goal, hard rules, phases, checkpoints completed, open items, next action, definition of done.
2. List living documents (registers, production logs, changelogs) by location. Do not copy them into the handoff.
3. Record open owner decisions as questions, never defaults.
4. At the start of the next session, read the handoff first, then the hard rules, then the task.
5. Keep a per-project context layer (instructions file, summary, memory) updated when documents change.
6. Never overwrite a prior handoff; increment the version.

Gate: handoff is saved before the session ends and the coordinator confirms it.
