# Memoir Anti-Slop

## When to use
Every drafting loop iteration, after assertion audit and before the human pass.

## Principle
Slop is defined relative to the subject. A phrase is slop if it is far outside the subject's baseline, not because it is on a generic list. Keep a small kill list for universal tells.

## Steps
1. Build the slop baseline from the subject's exported writing (rates of stock phrases, hedges, abstract nouns, adjective stacks, em-dashes, tricolons).
2. Set floors and ceilings per metric from the baseline and record them before measuring.
3. Measure each chapter draft. Report metric, subject value, threshold, direction (floor or ceiling).
4. Rewrite flagged passages by returning to the source material, not by thesaurus swapping.
5. Human pass: read the chapter aloud with about eleven spoken-aloud questions (does this sound like them; would they say this; is each detail theirs; is anything too tidy; does the ending over-explain; and similar).
6. Apply the rewrite rule: if a passage fails twice, hand it to the subject to write.

## Universal kill list (extend per brand voice)
Filler openers, "not just X, it is Y" constructions, three-adjective stacks, rhetorical questions as transitions, summary sentences that restate the paragraph.

## Gates
Never move a threshold to pass a chapter. Log the changelog line for each revision.
