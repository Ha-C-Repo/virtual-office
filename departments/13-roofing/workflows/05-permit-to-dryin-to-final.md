# 05 Permit to Dry-In to Final Inspection

Owner: production-manager | Approver: {{OWNER}}; quality-inspector signs checkpoints

## Steps
1. Build the permit packet (`../templates/permit-packet-checklist.md`); run `../skills/permit-and-code-check/SKILL.md`.
2. GATE (human): owner or production manager signs the packet; permit issued and posted.
3. Pre-start QC (`../skills/qc-checklists/SKILL.md`): materials, color, safety plan, protection.
4. Tear-off. Photograph the deck. Replace damaged decking, re-nail; photos before cover. Hidden-decking cases go to the supplement or change order process.
5. Install ice barrier where required, underlayment with proper laps, drip edge; flash valleys and penetrations.
6. GATE: dry-in QC and photos; request the jurisdiction's inspection if required; no shingles until the dry-in is accepted where the jurisdiction requires it (VERIFY).
7. Install shingles per manufacturer instructions; flashing, vents, ridge.
8. Final QC and cleanup (magnet sweep) (`../templates/qc-checklist.md`).
9. Request the final inspection; fix any correction items; retest.
10. Record the permit final in the project file; start closeout (`09-closeout-to-final-payment.md`).

## Outputs
Permit record, inspection results, dated photo sets, QC checklists.
