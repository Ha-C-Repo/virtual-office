# Change Order / Scope-Drift Workflow

Skill: `../skills/change-order/SKILL.md`.

## Steps
1. Monitor correspondence and requests for: commitments beyond the signed agreement; compensation arrangements outside the grid process; vendor term changes mid-contract; brand-use expansion; scope growth.
2. Qualify: drift or clarification. If unclear, ask one question.
3. Draft the numbered amendment (`../templates/amendment.md`). Economics go in the `-INT` memo only.
4. Add a signature-gate row to the obligations register.
5. GATE: principal approval; counsel flag as needed.
6. Both parties sign. No work on the changed scope before that.
7. Log the signed amendment; update the grid or tracker if affected.

## Sign-off
Principal. Counterparty signature required before any change takes effect.
