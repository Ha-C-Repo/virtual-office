# Proposal format

## When to use
Producing the agent recruiting one-pager or any outward PDF.

## Steps
1. Use `../../templates/agent-recruiting-one-pager.md`. The single-page structure is locked: do not add sections.
2. Income language is qualitative only. No compensation, commission or override figures.
3. Never assert branch production, size or track record without {{PRINCIPAL_ROLE}} confirmation.
4. Apply the demonstration label until the engagement is live. Logos from approved masters only, none in demo status.
5. Assign a document number (`../../knowledge/rules.md`, numbering section) and create the `-INT` memo.
6. Export PDF and run visual QC.

## Outputs
PDF plus internal memo.

Full chain in `../../workflows/outward-deliverable-chain.md`.
