# Carrier comparison

## When to use
When an agent prepares a plan comparison for a client.

## Inputs
Client inputs: medication list transcribed exactly, providers, preferred pharmacy, budget.

## Steps
1. Retrieve benefits live from approved sources (the corporate plan-benefit lookup or the federal plan finder). Never from memory or a cache.
2. Fill the twelve-factor worksheet: premium, deductible, maximum out-of-pocket, drug formulary and tier for each listed medication, pharmacy network, provider network, star rating, primary and specialist copays, extra benefits, out-of-network rules, plan year, effective date. Show the arithmetic for annual cost.
3. Hand to the agent. The agent completes it with the client.

## Outputs
Completed worksheet with sources and date retrieved.

## Gates
The AI never renders the verdict. No misleading side-by-side. Carrier names only per appointment status. Worksheet contains client data and stays internal unless the client receives it from the agent.
