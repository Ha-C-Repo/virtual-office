# Change order (amendment)

## When to use
When correspondence or a request goes beyond the signed agreement: commitments beyond scope, compensation arrangements outside the grid process, vendor term changes mid-contract, brand-use expansion, scope growth.

## Steps
1. Detect: scan the correspondence register and incoming requests for out-of-scope signals.
2. Qualify: drift or clarification. If unclear, ask one question.
3. Draft a numbered amendment with `../../templates/amendment.md`: parties, number, description, reason, effective date, signature blocks. Economic impact goes in the `-INT` memo only.
4. Log in the obligations register as a signature gate.

## Gates
No work proceeds on the changed scope without a signed amendment. Principal approves; counsel flag as in `../contract-notice/SKILL.md`.
