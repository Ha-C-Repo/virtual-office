# Harnesses: 03-real-estate

Stdlib Python 3 tools with self-tests. Numbers from these tools win over model arithmetic. Selftest figures are illustrative; real inputs come from the owner or from dated documents.

| File | Purpose |
|---|---|
| `net_sheet.py` | Seller net sheet and CMA adjusted-price statistics. |

Run `python net_sheet.py --selftest` after any change. Run `python net_sheet.py --help` for usage.
