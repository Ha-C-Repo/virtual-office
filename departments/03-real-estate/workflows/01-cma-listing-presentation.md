# 01 CMA and Listing Presentation

Owner: listing-cma-analyst | Reviewer: compliance-reviewer | Approver: {{OWNER}}

## Steps
1. Inventory and classify documents (`../skills/listing-doc-classifier/SKILL.md`). Flag gaps. GATE: incomplete record set stops here.
2. Source GLA by ranked order: records or measured sketch (HIGH), scaled floor plan (MEDIUM), photo-inferred or assumed (LOW).
3. Select comps; each has address, sale price, GLA, sale date, source.
4. Build the adjustment grid with a calculator or script. No arithmetic in prose.
5. Produce three scenarios: aggressive, recommended, floor.
6. Run sanity gates (`../skills/cma-sanity-check/SKILL.md`): price versus corridor, GLA sourced, photos present, disclosure checklist complete. GATE: any failure blocks.
7. Four-pass review: calculation, fact, compliance, voice.
8. Generate the PDF pair: client document and internal "-INT" twin (`../templates/listing-presentation-client.md`, `../templates/listing-presentation-internal.md`). Run the export validator (`../skills/two-pdf-pair-check/SKILL.md`). Non-zero exit blocks.
9. Scrub (`../skills/client-doc-scrubber/SKILL.md`).
10. SIGN-OFF: principal approves the recommended price and releases the client copy.

## Locked client section order
Header band; property info grid; hero image; listing services; service scope table; capabilities; comparable sales grid; price strategy with recommended-price row; tour preview (labeled); exclusions; engagement terms and milestones timeline; signature block with fair-housing line and footer.

## Outputs
Client PDF, internal PDF, gate reports, hash entries in the document log.
