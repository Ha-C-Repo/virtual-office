# Panel and judge

## When to use
Open questions with no single right answer: strategy options, naming, structure, risk review, design alternatives.

## Do not use for
A price, rate, identifier, count, date, regulatory rule or any fact that has a source of record.

## Steps
1. Write the question once, with the decision it supports and constraints. Do not leak a preferred answer.
2. Run it in three to five independent sessions (different models or fresh sessions). No session sees another's answer.
3. Collect answers verbatim.
4. Judge step: a separate session reads all answers and writes (a) consensus, (b) conflicts with the reasons for each side, (c) gaps no one covered, (d) unique insights worth keeping, (e) a recommendation with the human decision needed.
5. Check any factual claim in the synthesis against sources before it is used.
6. File the question, the answers and the synthesis together.

## Outputs
Synthesis document with the five parts above.

## Gates
Judgment is advisory. The human decides. Panel output is LOW confidence for any fact it states.

## Anti-patterns
Averaging opinions. Running the panel to avoid deciding. Using it where a calculator or register answers the question.
