# Workflow: Document Drafting to Sign-off

Skill: `../skills/document-drafting/SKILL.md`. Chain: `outward-deliverable-chain.md`.

| # | Step | Output | Gate |
|---|---|---|---|
| 1 | Define goal, audience, band, sources (`../skills/thinking-protocol/SKILL.md`). | Five-line plan | Sources listed or the gap is named |
| 2 | Pick the template from `../templates/`. Copy it. | Working copy | Never edit the master |
| 3 | Fill fields from sources. Mark `NEEDS_INPUT` for gaps. | Draft v1 | No invented facts |
| 4 | Answer first, then support. Match reading level to audience. | Draft v2 | |
| 5 | Number the document and create the twin. | `{{DOC_NUMBER}}`, `-INT` | Pair rule |
| 6 | Voice check, QA, compliance as the band requires. | Gate results | PASS required |
| 7 | Counsel flag for indemnity, termination, regulatory, insurance, liability text. | Counsel note | Draft only; not legal advice |
| 8 | Human sign-off. | Approval record | Version-specific |
| 9 | Export and file; changelog line; prior version archived. | Final file | Backup before overwrite |
| 10 | Schedule any follow-up or deadline watch. | Calendar entry | `../skills/scheduling-and-routines/SKILL.md` |
