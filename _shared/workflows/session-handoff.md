# Workflow: Session Handoff

Skill: `../skills/handoff-writing/SKILL.md`. Template: `../templates/handoff.md`.

| # | Step | Who | Gate |
|---|---|---|---|
| 1 | Stop adding scope. List what is in flight. | Coordinator | |
| 2 | Verify each "closed" item with the check actually run and its result. | QA editor | No evidence, not closed |
| 3 | Sort remaining work by what unblocks it. Name owner and blocker. | Coordinator | |
| 4 | Record decisions made and pending (decision log). | Records keeper | |
| 5 | Label measured vs assumed facts; date measurements. | Coordinator | |
| 6 | Pick up to five "read first" files. List living documents by path; do not copy them. | Coordinator | |
| 7 | Write the non-negotiables and the definition of done. | Coordinator | |
| 8 | Back up and file the handoff; update the project context layer memory file. | Records keeper | `safe-write-and-backup` |
| 9 | Test: a cold reader answers "where does this stand and what do I do first?" from the handoff alone. | QA editor | If not, rewrite |
