# Workflow: Customer Complaint Resolution

Skill: `../skills/customer-service/SKILL.md`. Templates: `../templates/service-recovery-email.md`, `../templates/escalation-note.md`.

| # | Step | Who | Gate / sign-off |
|---|---|---|---|
| 1 | Log the complaint: date, channel, issue category, masked account. | Records keeper | |
| 2 | Classify: (1) allegation of concealment, safety, illegal conduct, discrimination or legal threat; (2) service complaint; (3) specific praise; (4) generic. | Router | |
| 3 | Class 1: stop. Escalation note to the owner the same business day. No public draft. | Coordinator | Band WAIT; counsel flag considered |
| 4 | Class 2: gather facts from the records. Do not argue them. | Author agent | Verify, do not generate |
| 5 | Draft the recovery reply: acknowledge the specific issue, say what happens next, who, by when. No liability admission, no unauthorized promise. | Author agent | |
| 6 | Voice check and compliance check. | QA, compliance | |
| 7 | HUMAN SIGN-OFF for any public or written reply. | Owner role | BRIEF |
| 8 | Add every promise to the promise list with a date and owner. | Records keeper | |
| 9 | Track to closure. Any promise past date escalates the same day. | Coordinator | |
| 10 | Confirm resolution with the customer. Mark resolved only then. | Human | A posted reply is not a resolution |
| 11 | Weekly digest: volume, response time, repeat causes, open items. | Coordinator | |
| 12 | Root cause: if the same cause recurs, open a process fix (SOP update or skill). | Coordinator | `skill-promotion.md` |
